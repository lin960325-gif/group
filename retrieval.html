目前檢索方式

此 GitHub Pages 版本使用瀏覽器端關鍵詞重疊比對，依命中詞數排序，並顯示 Markdown 來源文件。它是可在靜態網站運作的檢索原型，不是向量資料庫，也不會自行呼叫 LLM 生成答案。

若要升級成真正的語意檢索／RAG，下一階段可加入 embeddings、向量索引與安全的後端 LLM API；API 金鑰不可放在公開 GitHub 前端。
